# Equal World Shipping Company Website

This is a static starter website for Equal World Shipping Company.

## Included
- Home page
- Services
- Shipment tracking page
- About section
- Contact section
- Uploaded company logo
- Mobile-responsive design

## Demo tracking numbers
- EWS100001
- EWS100002

IMPORTANT:
The tracking system is intentionally a DEMO. It does not verify or create real shipments.
For production use, connect it to a legitimate shipment database or carrier API and add appropriate authentication/admin controls.

## Run
Open `index.html` in a web browser, or upload the folder to a legitimate web host.
